# Google Docs Documentation

## 1. Introduction

Google Docs is a free, web-based word processing application developed by Google. It allows users to create, edit, format, and share documents online.

It is widely used for academic assignments, reports, project documentation, research papers, and collaborative writing.

## 2. Objectives

The main objectives of learning Google Docs are:

- To understand the Google Docs interface.
- To apply different text formatting options.
- To use headings and predefined styles.
- To insert tables, images, and hyperlinks.
- To manage page layout and document formatting.
- To use comments and suggestions.

## 3. Creating a Document

A new document can be created using the following steps:

1. Open Google Docs at https://docs.google.com/.
2. Sign in using a Google account.
3. Click on the Blank document option.
4. Enter a suitable document title.
5. Start writing the content.
6. The document is automatically saved to Google Drive.

## 4. Text Formatting

Google Docs provides several formatting options to improve document appearance and readability.

Some commonly used formatting options include:

| Feature | Purpose |
|---|---|
| Bold | Makes text appear darker and thicker |
| Italic | Makes text appear slanted |
| Underline | Draws a line below text |
| Font Size | Changes the size of text |
| Font Style | Changes the appearance of text |
| Text Color | Changes the color of selected text |
| Highlight | Highlights important content |
| Alignment | Aligns text to the left, center, right, or justified |

## 5. Headings and Styles

Google Docs provides predefined text styles that help organize long documents.

Common styles include:

- Title
- Subtitle
- Heading 1
- Heading 2
- Heading 3
- Normal Text

Headings improve document structure and make it easier to generate an automatic table of contents.

## 6. Creating Lists

Google Docs supports different types of lists.

### Bulleted Lists

Bulleted lists are useful for presenting information without a specific order.

Example:

- Introduction
- Objectives
- Methodology
- Conclusion

### Numbered Lists

Numbered lists are useful for presenting sequential steps.

Example:

1.Reach the airport.
2.Complete check-in and collect your boarding pass.
3.Pass through the security check.
4.Go to your boarding gate and wait for boarding.
5.Board the aircraft and enjoy your flight!


## 7. Inserting Tables and Images

Google Docs allows users to insert tables and images into documents.

### Inserting a Table

Steps:

1. Open the Insert menu.
2. Select Table.
3. Choose the required number of rows and columns.
4. Enter the required information.

Tables are useful for organizing structured information.

### Inserting an Image

Steps:

1. Open the Insert menu.
2. Select Image.
3. Choose the image source.
4. Select the image.
5. Adjust its size and position.

Images make documents more informative and visually appealing.

## 8. Page Setup and Layout

Google Docs provides page formatting options to control the overall appearance of a document.

Important settings include:

- Page orientation (Portrait and Landscape).
- Page size.
- Page margins.
- Page color.
- Page numbering.
- Headers and footers.

These options help create professional academic documents.

## 9. Table of Contents

Google Docs can automatically generate a table of contents using document headings.

Steps:

1. Apply heading styles to the document sections.
2. Place the cursor where the table of contents should appear.
3. Open the Insert menu.
4. Select Page elements and then Table of contents.
5. Choose the preferred format.

The table of contents can be updated when the document structure changes.

## 10. Sharing and Collaboration

Google Docs supports real-time collaboration.

Users can share documents with others and assign different access permissions.

Common permission levels include:

- Viewer: Can only view the document.
- Commenter: Can view and add comments.
- Editor: Can modify the document.

Multiple users can edit the same document simultaneously, and changes are saved automatically.

## 11. Practical Work

 The following activities can be practised using Google Docs:

- Creating a new document.
- Formatting text using different styles.
- Organizing content with headings.
- Creating numbered and bulleted lists.
- Inserting tables and images.
- Adjusting page layout.
- Generating a table of contents.
- Adding comments and suggestions.
- Sharing documents with collaborators.
- Downloading documents in PDF format.

## 12. Conclusion

Google Docs is a useful tool for creating and managing professional documents. It provides a simple interface along with powerful formatting, editing, and collaboration features.
