16. Useful Git Command Summary

Command

Purpose

git --version

Check Git version

git init

Initialize a repository

git clone

Clone a repository

git status

Check repository status

git add .

Stage changes

git commit -m

Create a commit

git log

View commit history

git diff

Compare changes

git branch

List branches

git checkout

Switch branches

git switch

Switch branches

git merge

Merge branches

git remote -v

View remote repositories

git push

Upload commits

git pull

Fetch and integrate changes

git fetch

Download remote updates

git rm

Remove tracked files

git mv

Rename or move tracked files

git restore

Restore file changes

git reset

Move branch history pointer

git stash

Temporarily save changes
